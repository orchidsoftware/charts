# Orchid Charts: аудит стабильности и подготовка 0.0.5

Дата первоначального аудита: 2026-09-06. Исходный commit: `6ae283c`.
По решению автора следующий выпуск — **0.0.5**. Эта работа не объявляет API
стабильным и не поднимает версию до 1.0.0.

## Методика

Первоначальная матрица включала десять направлений. Восемь отдельных агентов
проверяли разные области, не знакомясь с выводами друг друга. После ограничения
инструмента два направления — безопасность и документация стабильности — проверил
основной агент. Это восемь независимых агентных оценок и два дополнительных
прохода, а не десять независимых экспертов.

Apple и Laravel — ориентиры качества UX и DX, а не авторы этого заключения.
Критерий блокера: неверные данные, нарушение документированного поведения или
непрохождение действующего условия выпуска. Новые типы графиков, framework
wrappers и количество звёзд GitHub не являются условиями стабильности API.

## Дополнительные исправления

- Экстремальные диапазоны и переполненные totals отклоняются до замены графика.
  Константный ряд порядка `1e18` отображается; диапазоны за пределами точности
  JavaScript возвращают явную ошибку вместо NaN-геометрии. Это не обещание
  поддержки любых конечных чисел во всех комбинациях.
- Escape снимает `aria-pressed` у dense selection.
- Настройка скрытия dots сохраняет targets для inspection.
- Ошибка данных указывает имя серии и позицию некорректного значения.
- Размеры комбинаций импортов описаны как диагностика; обязательный gate
  относится к каждому отдельному семейству вместе с CSS.
- Prerelease-публикация использует npm-канал `next`, обычный выпуск — `latest`.

## Проверки выпуска

Обязателен полный `npm run check`: форматирование, lint, policy tests, три режима
TypeScript, браузерные контракты и visuals с 100% покрытием, performance budgets,
Chromium/Firefox/WebKit, touch, Turbo, размер сборки и consumer npm-архива.
Дополнительно выполняются audit, demo build и проверка состава архива.

Локальный `npm run check` для 0.0.5 прошёл: 689 тестов основного набора,
100% statements/branches/functions/lines, performance и compatibility gates,
touch и Turbo, импорты архива в трёх режимах TypeScript. Максимальный импорт
семейства вместе с CSS — 22 994 gzip-байта при лимите 23 000. После обновления
тестового Turbo до 8.0.23 повторно прошёл его smoke test; npm audit сообщает
0 уязвимостей. Demo build и проверка состава архива также прошли.

Touch smoke использует браузерный touchscreen tap и распознанный Chromium
scroll-жест, начатый над графиком. Отдельная проверка Chromium accessibility tree
подтверждает передачу точных значений при отключённом tooltip. Это не заменяет
ручной проход VoiceOver/NVDA и тест на физическом устройстве; соответствие WCAG
этим отчётом не сертифицируется.

Linux-эталоны получают через workflow Update Linux Screenshots и просматривают
до коммита. Зелёный CI требуется на точном SHA, выбранном для выпуска. Сам факт
обновления эталонов не считается успешной проверкой регрессий.

## Что остаётся до решения о 1.0.0

После закрытия обнаруженных дефектов и зелёного CI необходимо отдельное решение
автора о заморозке публичного контракта. До него полезен ручной проход с screen
reader и touch-устройством, а также проверка интеграций в реальном приложении.
Текущий выпуск остаётся 0.0.5; новые возможности и wrappers не добавлены в список
обязательных условий 1.0.
